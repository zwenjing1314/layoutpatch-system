## 5. 下一轮唯一主要任务

**阶段1B：完成“登录 → 授权范围内真实检索 → 受保护页面预览”的网页闭环。**

1. 按设计选择性迁入Snappy所需前后端模块，记录来源和许可，建立独立启动配置。
2. 初始化admin/A/B、SQLite文档归属和服务端会话；从首条业务路由加入认证、对象授权和必要CSRF防护。
3. 将本轮真实完整页面特征写入独立Qdrant；后端先生成可访问文档版本白名单，再执行新问题编码与范围内Top-k。
4. 网页输入实际新问题并预览结果；用直接HTTP请求证明未登录被拒、A无法访问B、退出后原预览URL失效；Qdrant与参考评分/排名一致。

出口是可演示、可测试的受保护网页主线。上传/区域高亮、完整管理页仍留后续阶段；1A成功不表示这些功能已完成。适用T01—T03/T05/T06/T11逐项记录子集，不提前宣布整项全过。
