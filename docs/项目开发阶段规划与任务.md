## 2. 所有阶段共同遵守的规则

- 只改独立`layoutpatch-system`；旧`layoutpatch`、`layoutpatch-evidence`、`Snappy`只读。不下载模型、不训练、不换底座、不覆盖旧研究结果，不擅自暂存、提交或推送。
- 复用原ColPali、既有D-no-text身份及已核实的Snappy工程机制；新增代码说明来源。身份、坐标或评分不一致先定位，不降低阈值或换模型掩盖失败。
- 每批先检查实际代码、依赖、端口和数据，再备份受影响状态；历史PID、报告、计划不等于当前运行结果。开发验收使用隔离数据，正式数据变更需在该批明确范围。
- 后端以当前会话和数据库归属决定权限；上传owner由服务端决定。任务、图片、区域、历史、文件均须独立鉴权，不能只隐藏按钮。
- 测试替身可验证错误路径，但真实页面编码、问题编码、解析与区域推理必须另留真实证据。错误、空结果、超时要明确显示，不能回放旧结果或编造框。
- 每批交付“目的、改动、检查、失败/阻塞、口述、下一唯一任务”，随后停止。日期和批次编号固定，不以一次对话打包完成整个阶段。

### 5.3 效果评价怎样做，哪些结论不能混用

4-1B先做资料盘点和人工标签核对，再决定规模。建议从本机合法可用的3—5份完整PDF、20—30道明确问题起步，覆盖文字/表格/图等实际可用证据；这是工作量建议，不是已选语料或统计充分性承诺。不为凑数量下载、截页或虚构题目/标签。R22/R33及研究开发已用样例标为已见；重复使用只能称固定样例评价，不能称未见测试。

| 评价对象 | 建议记录 | 解释边界 |
|---|---|---|
| 页面检索 | Hit@k（前k页是否含任一相关页）、MRR@k（首个相关页倒数排名）；相关页标注完备时再报Recall@k | k、截断、并列、多相关页/无答案题的规则在4-1B固定；每题使用该账号有权访问的完整页面库，不先挑答案页 |
| 页内定位 | 给定正确页时，Top-m区域与人工证据的匹配/IoU阈值通过率；另报解析候选覆盖情况 | 用人工相关页限定“正确页条件下”评测，但人工证据框不送入候选生成或D推理。多证据框、空候选、候选漏检分别记，不能只保留有候选的好题 |
| 端到端 | 按固定查看页面/区域数量与顺序，逐题记录整链是否找到合格证据 | 页面未命中、解析/推理错误均影响结果；不能把页面命中率乘条件定位率代替实际端到端结果 |
| 算法一致性 | 固定身份及同Q官方页面/原D数值参考，原容差保持 | R33的小数差/排序一致只证明实现对齐，不能当检索或定位准确率 |

成功率分母包含全部冻结的有效题；超时、依赖失败、无命中分别报告，不静默剔除。不具备可信标签时，只交付协议/阻塞及可测工程指标，不编造准确率。首版无需再做训练、全套研究消融或方法二对比；论文系统章节与研究实验来源分开。

### 5.4 性能与成本的实际口径

4-2B在当前机器预检后固定CPU/GPU、dtype、线程、完整页数、向量数、问题长度、k与缓存状态。R33使用冻结BF16 CPU，单页编码曾约205秒；不能据此承诺GPU速度或用HTTP总时间替代模型耗时。先做小样本测时，再在已有支持范围内设定明确总时限和停止条件，不能无限重试。

分别记录上传→可检索、解析候选就绪、问题编码、向量查询、D定位及端到端耗时；排队/加载/准备与forward分开，P′命中/未命中分组。相同问题的主动提交仍新编码，打开历史的无推理耗时另列，不混入检索速度。失败/取消后继续完成的调用仍计成本。

至少20次串行请求是小样本描述，不是容量证明；冷启动单列，保留每次耗时和失败。小规模竞争可从两个客户端开始，仍保持每数据库一个后端worker和既有模型串行机制，检查有限队列、busy/超时提示及状态正确性；请求数、上限、持续时间在执行前冻结。GPU allocated/reserved、进程内存、实际磁盘增量和逻辑BF16/float32字节分别报告；旧代、失败候选、缓存与全代复制占用不能忽略。

### 5.5 部署与恢复的独立检查点

4-3A先形成具体可执行的部署包/步骤及隔离演练证据；**本规划不授权正式写入，只有用户明确指定4-3B或正式启用时才切换。** 执行前新查PID/命令/创建时间、正式schema、未提交差异和备份，不沿用R33快照。先冻结写入并等任务到安全检查点，按一致恢复点备份SQLite（处理WAL）、源文件/派生特征/候选/缓存、全部必要Qdrant代、配置及schema身份；不在业务仍写入时零散复制文件冒充一致备份。

必须验证恢复后的向量/payload、活动指针/epoch、文档版本和文件哈希一致；索引回退不等于整套数据库/文件恢复。回退不能只换旧前端或盲目降schema；使用同一恢复点的兼容代码/配置/数据库/文件/索引。切换验收前不开放普通业务写入；存在备份后新增、撤权或删除时，先核对变更并落实墓碑/共享撤回及会话失效，未核对完成不得对外服务，不能让旧Cookie或已删文档借恢复复活。

本机正式启用是首版目标；外部新机器仅在用户另行提供并指定环境、资源与时间后验证。缺外部环境时交付本机实测与离线依赖/资源清单，外部复现明确未验，不自动下载模型补环境。演示需要证据定位时使用明确已具完整特征/解析的自有样例；原13页unavailable不偷偷补成已解析。
