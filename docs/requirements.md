## 2. 两项研究在系统中的位置

研究编号按用户2026-11-07说明固定，编号不代表系统执行先后；本节R13补充仅澄清术语与接入顺序。

1. **方法一：页内证据定位／区域排序**：对返回页面的既定解析候选进行排序。D-no-text 使用页面完整视觉 patch、候选框/类型/空间关系；它不负责找到正确页面，不生成任意新框，不生成答案。
2. **方法二：预算约束下的视觉文档检索**：冻结 ColPali，将问题与文档库页面匹配；预算方法研究全库总向量数固定时的页面间分配。首版先使用完整多向量基线，预算研究未验证时明确显示“基线”，不宣布研究完成。

当前实际接通的是原ColPali基线页面检索，方法一的系统真实推理与高亮尚待阶段2；方法二也未接入。先完成“基线找页→方法一定位”的系统，之后方法二在检索策略、索引与配置层适配，并继续保留供D使用的完整特征；不是复制算法文件即可启用。新窗口指令和适配条件见[阶段2接手指南](阶段2新窗口接手指南.md)。

历史的区域成绩以“正确页面已给定”为条件，不是新系统端到端准确率。本轮没有重算论文指标。三 seed 的历史统计与系统固定单个 seed 的部署身份分开记录。

## 3. 账号和可见性默认规则

首个管理员由交互式初始化命令创建；密码不写入代码、Git 或命令行参数。之后由管理员创建普通用户并交付临时密码，首次登录强制修改。普通用户只能修改自己的密码，不能写角色或 `owner_id`。用户名唯一；停用账号保留其文档，撤销其所有会话。管理员不能停用最后一个启用管理员。

普通上传固定为 `owner_id=当前登录用户`、`visibility=private`。仅管理员可发布自己上传的资料到共享库；禁止通过通用更新接口把别人的私有文档改为共享。共享库对所有启用的已登录用户只读。

管理员有全库管理权限，涉及他人私有文档或历史的读取/检索/删除均记录操作者、对象、时间、原因。工作台默认仍为“本人＋共享”，进入管理范围才访问全库，避免无意混入私人资料。登录/帮助说明应告知这项管理员权限。

| 操作 | user | admin |
|---|---|---|
| 登录、退出、改自己的密码 | 允许 | 允许 |
| 上传 PDF、查看本人任务 | 允许 | 允许 |
| 搜索/预览/下载本人私有与共享文档 | 允许 | 允许 |
| 搜索/预览其他用户的私有文档 | 禁止 | 管理范围内允许，留痕 |
| 查看他人历史或任务 | 禁止 | 管理范围内允许，留痕 |
| 删除文档 | 仅本人私有文档 | 全库，留痕 |
| 发布/撤下共享 | 禁止 | 仅管理员上传的资料 |
| 创建/停用用户、重置密码 | 禁止 | 允许，留痕 |
| 切换已验证配置、重建索引 | 禁止 | 允许，留痕 |
| 修改任意模型名、直接调用模型/向量库 | 禁止 | 前端也不提供这种入口 |

## 4. 最少页面与异常表现

- 登录页：账号、密码、统一失败提示；不提供角色自选。
- 用户工作台：本人私有文档、共享入口、上传、入库进度及失败重试。
- 检索页：问题、Top-k、范围；展示“相关页面”、文档名、从 1 开始的页码和耗时。
- 页面详情：与检索页联动的原页预览、候选框、区域排序与高亮开关。
- 管理页：账号、共享资料、系统任务、索引和已验证配置。

页面命中而区域失败时保留页面结果，提示“候选区域未生成/解析失败/排序失败”，不伪造框。排序分数不能称“答案正确率”或概率。不可用功能不显示为可点击的完成态。

## 5. 数据与隐私边界

后端对搜索、缩略图、PDF、页面图片、区域、裁剪、下载、任务、历史和删除逐对象授权。文件路径/随机 ID 不代替权限；文件名不作删除键。未认证为 401，角色不足为 403，他人对象与不存在对象统一返回 404，避免对象存在性泄露。

缓存、日志和浏览器状态也是隔离范围：退出时清空前端搜索与预览状态；受保护响应不做公共缓存。管理员日志不记录密码、Cookie、完整会话令牌或服务密钥；查询问题存入受保护的历史表，普通访问日志不打印全文。
